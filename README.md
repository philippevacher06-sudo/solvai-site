# SOLVAI — US500 Intelligence Lab

Vitrine publique sur GitHub Pages, domaine `solvai.fr`.

## Périmètre public

- Observatoire pédagogique du S&P 500 et de ses facteurs macroéconomiques.
- Sources primaires : Federal Reserve, BLS, BEA, Treasury, S&P DJI, SEC, EIA, Cboe.
- Description générale du processus collaboratif de recherche en intelligence artificielle.

## Interdictions éditoriales permanentes

Ne jamais publier les règles de stratégie, paramètres de trading, signaux, code du moteur, comptes, positions, journaux privés, P&L, rendements, taux de réussite ou bilans de trading. Ne pas publier de conseil individualisé ou d'incitation à négocier des CFD. Ne pas inventer de statistiques « temps réel ».

## Technique

Site statique, HTML/CSS/JS, sans système de collecte de données personnelles. Le graphique US500 Pepperstone est fourni par un module tiers TradingView ; ce cours ne correspond pas nécessairement au CFD Pepperstone US500. Les données externes peuvent être différées. Les calendriers macro sont éditoriaux et doivent être datés et vérifiés avant modification.

L'outil OAuth personnel sous `/us500-win-drive/` est conservé indépendamment de la navigation publique.

## Publication

`main` est la branche publiée par GitHub Pages. Préparer un changement sur une branche, vérifier les liens, contrôler la confidentialité et faire relire avant fusion. Conserver `CNAME` et `.nojekyll`.
